L'applicazione costruirà un URL di autorizzazione OAuth 2.0 verso Microsoft Entra ID con questi parametri:

// Configurazione OAuth 2.0
const authConfig = { tenant: 'acmecorp.onmicrosoft.com', clientId: 'a1b2c3d4-e5f6-7890-abcd-ef1234567890', redirectUri: 'https://portal.acmecorp.com/auth/callback', scope: 'openid profile email' }; // URL di autorizzazione Microsoft const authUrl = `https://login.microsoftonline.com/${authConfig.tenant}/oauth2/v2.0/authorize? client_id=${authConfig.clientId}& response_type=code& redirect_uri=${authConfig.redirectUri}& scope=${authConfig.scope}& state=abc123xyz`; // Reindirizzamento window.location.href = authUrl;

🔐 Cosa fa Microsoft Entra ID?

1. Verifica le credenziali contro Active Directory
2. Controlla le policy di sicurezza (MFA, Conditional Access)
3. Genera un authorization code
4. Ti reindirizza all'app con questo codice

⚙️ Elaborazione Callback

📍 Microsoft ti ha reindirizzato a:

https://portal.acmecorp.com/auth/callback?code=0.AXoA...TkwNQ&state=abc123xyz

1. Estrazione dell'authorization code L'app legge il parametro code dall'URL
// callback.js - Pagina di callback
// Estrae il codice dall'URL const urlParams = new URLSearchParams(window.location.search); const code = urlParams.get('code'); const state = urlParams.get('state'); console.log('Authorization Code ricevuto:', code);
2. Scambio code per access token (lato server!) Il server fa una chiamata POST a Microsoft per ottenere il token
// server.js - Scambio del codice
// Chiamata al token endpoint di Microsoft const tokenResponse = await fetch( 'https://login.microsoftonline.com/acmecorp.onmicrosoft.com/oauth2/v2.0/token', { method: 'POST', headers: { 'Content-Type': 'application/x-www-form-urlencoded' }, body: new URLSearchParams({ client_id: 'a1b2c3d4-e5f6-7890-abcd-ef1234567890', client_secret: 'YOUR_CLIENT_SECRET', code: code, redirect_uri: 'https://portal.acmecorp.com/auth/callback', grant_type: 'authorization_code' }) } ); const tokens = await tokenResponse.json(); // tokens = { access_token, id_token, refresh_token, expires_in }
3. Validazione e decodifica dell'ID token Verifica la firma JWT e estrae le informazioni utente
// Decodifica del JWT ID Token
const jwt = require('jsonwebtoken'); // Verifica e decodifica l'ID token const decoded = jwt.verify(tokens.id_token, publicKey, { algorithms: ['RS256'], issuer: 'https://login.microsoftonline.com/.../v2.0' }); console.log(decoded); // { // aud: "a1b2c3d4-e5f6-7890-abcd-ef1234567890", // iss: "https://login.microsoftonline.com/.../v2.0", // iat: 1704967200, // exp: 1704970800, // name: "Mario Rossi", // preferred_username: "mario.rossi@acmecorp.com", // oid: "00000000-0000-0000-0000-000000000000", // tid: "tenant-id" // }
4. Creazione sessione applicazione Crea una sessione locale e salva i token in modo sicuro
// Creazione sessione
// Crea sessione nel database const session = await db.sessions.create({ userId: decoded.oid, email: decoded.preferred_username, name: decoded.name, accessToken: tokens.access_token, refreshToken: tokens.refresh_token, expiresAt: new Date(decoded.exp * 1000) }); // Imposta cookie di sessione res.cookie('session_id', session.id, { httpOnly: true, secure: true, sameSite: 'lax', maxAge: 3600000 }); // Reindirizza alla dashboard res.redirect('/dashboard');

🔑 Come funziona l'accesso alle altre app?

Con Access Token Ogni app Microsoft accetta lo stesso access token ottenuto da Entra ID. Non serve re-autenticarsi!
// Chiamata API a un'altra app Microsoft const response = await fetch('https://graph.microsoft.com/v1.0/me', { headers: { 'Authorization': `Bearer ${accessToken}` } });
Con Single Sign-On (SSO) Il browser mantiene cookie di sessione su login.microsoftonline.com. Se accedi a un'altra app Microsoft, vieni autenticato automaticamente senza inserire la password!
🎫 Access Token (esempio):
eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiIsIng1dCI6Ik1yNS1BVWliZk...

Valido per: 1 ora
Scopes: openid, profile, email, User.Read
Refresh disponibile: Sì (valido 90 giorni)
